# 兔仙人说AI - 配图生成大师Skill

基于ian-xiaohei-illustrations风格，经过6轮深度优化打磨的配图方法论，用于"兔仙人说AI"头条号文章的封面图和正文配图生成。

## 核心特色

- **情感曲线**：6张图有完整的情感起伏（悬念→惊讶→佩服→怀疑→洞察→参与）
- **多层隐喻**：每张图同时包含表层（舞台表演）+中层（流量游戏）+深层（时代镜像）
- **统一符号系统**：小黑、喇叭、聚光灯、眼睛、齿轮、天平、问号、舞台
- **品牌资产**：统一编号、标识、颜色语义、字体风格
- **质量评估**：8项标准打分，低于4分重新优化
- **模板库**：5种文章类型的配图模板（时政/汽车/科技/人物/热点）

## 快速开始

1. 阅读 `SKILL.md` 了解完整方法论
2. 按照8步SOP生成配图
3. 使用8项标准评估质量
4. 优化迭代2-3轮
5. 发布并归档
