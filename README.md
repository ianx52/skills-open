# 兔仙人 · 自媒体方法论 Skill 库（公开版）

> 一套用「控制变量」方法打磨的自媒体创作方法论 Skill，**独立可用、可单独验证、可迭代**。
> 每个 Skill 都是一个完整的能力单元——做出来、用起来、有效果，用真实数据说话。

---

## 这是什么

「兔仙人说AI」在今日头条/公众号做 AI 产业内容。为了把内容质量做稳定、把每个创作环节的效果验证清楚，我们把整个创作流程拆成独立 Skill。

**核心理念——控制变量**：每个 Skill 只负责一个环节，职责单一；每个环节的产出都能用对应的数据指标单独验证：

| 环节 | 验证指标 |
|------|---------|
| 选题 | 打开率 / 阅读推荐比 |
| 配图 | 完读率、阅读时长 |
| 排版 | 完读率、滚动深度 |
| 发布 | 发布成功率、审核通过 |

---

## Skill 总览

| Skill | 环节 | 职责 |
|-------|------|------|
| `ian-topic-finder` | 选题 | 5维评分、生命周期、角度5法、语气设计、评论挖掘、选题库管理 |
| `ian-illustration-master` | 配图 | 「小黑」IP 手绘体系、结构化生图 Prompt、长文/微头条配图规格 |
| `ian-typography-master` | 排版 | 简洁清爽排版规范、颜色语义系统、移动端可读优先 |
| `toutiao-publisher` | 发布 | 头条后台（mp.toutiao.com）上传全流程，含配图同批插入 |
| `tu-xianren-illustrations` | IP素材 | 「兔仙人/小黑」插画风格与素材库 |

---

## 怎么用

1. 每个 Skill 目录内含 `SKILL.md`（完整方法论 + 检查清单）和 `README.md`（快速上手）
2. 创作流程按环节调用对应 Skill：选题 → 配图 → 排版 → 发布
3. 每个 Skill 独立可用，可单独验证效果、单独迭代升级

本仓库只收录**纯方法论** Skill（公开可见，展示实力）。
