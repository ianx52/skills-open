# 选题大师Skill（ian-topic-finder）

> 从信息洪流中筛选出"五维达标"的好选题，设计独特角度和语气，并管理专题系列。
>
> **版本**：v0.3.0｜ **创建**：2026-08-31｜ **更新**：2026-08-31

---

## 这是什么

一个选题Skill，帮你解决"今天写什么"的问题。

核心信念：**选题决定下限，写作决定上限。好选题 = 新鲜事件 × 独特角度 × 恰当语气。**

## 能做什么

- **信息源监控**：AI+时政、AI+汽车、通用热点三大类，20+信息源
- **5维判断标准**：时效性、热度、差异化、信息增量、跟读者关系（每维含关键子项）
- **话题生命周期分析**：5阶段 + 量能判断（识别真爆发vs假信号）
- **5法角度设计**：反常识法、信息增量法、身份代入法、冲突对比法、趋势预判法
- **语气设计**：5种语气（冷峻拆解/幽默反讽/焦虑预警/自豪叙事/科普解惑）
- **评论挖掘法**：含5步可执行操作流程，从爆款评论找选题
- **SEO关键词热度评分** + **品牌匹配检查**
- **选题库管理**：含专题/系列字段（点状→线状）
- **11项检查清单**：含钩子强度自评（1-5分）

## v0.3.0 精修内容

基于三方对比（content-ideas/李继纲/TrendRadar）+ 智囊团5位大神共识：
1. 5维加子项（每维1-2个关键子项）
2. 生命周期加量能判断（真爆发vs假信号）
3. 新增语气设计（差异化第三层）
4. 评论挖掘补可执行操作流程（5步）
5. 选题库加专题/系列字段（点状→线状）
6. 检查清单加钩子强度自评（1-5分，清单8→11项）

## 怎么用

1. 扫描信息源，收集候选选题
2. 品牌匹配3问 → 不匹配直接放弃
3. 话题生命周期判断 + 量能验证
4. 5维评分，≥3.0入库
5. 归入专题/系列
6. 从高优先级选题中选1个，5法设计角度 + 选语气 + 评论挖掘验证
7. 过11项检查清单（含钩子强度自评）
8. 交给写作Skill产出

详细使用流程见 [SKILL.md](./SKILL.md)。

## 与其他Skill的协作

| Skill | 职责 |
|-------|------|
| **ian-topic-finder**（本Skill） | 写什么（选题+角度+语气） |
| ian-toutiao-writer | 怎么写（标题/开头/结构/金句/结尾） |
| ian-illustration-master | 配图（封面+插图） |
| ian-typography-master | 排版（可读性） |
| toutiao-publisher | 发布（上传到平台） |

**控制变量法**：每个Skill的效果可独立验证——选题看点击率，写作看完读率，配图看点击率提升，排版看完读率。
