# 选题大师Skill（ian-topic-finder）

> 从信息洪流中筛选出"五维达标"的好选题，设计独特角度和语气，并管理专题系列。
>
> **版本**：v0.5.0｜ **创建**：2026-08-31｜ **更新**：2026-09-03

---

## 这是什么

一个选题Skill，帮你解决"今天写什么"的问题。

核心信念：**选题决定下限，写作决定上限。好选题 = 新鲜事件 × 独特角度 × 恰当语气。**

## 能做什么

- **信息源监控**：AI+时政、AI+汽车、通用热点三大类，20+信息源
- **一句话内核**：新鲜瞬间 × 独特角度 × 读者身份（选题前默念三遍，三问答不上直接放弃）
- **5维判断标准**：时效性、热度、差异化、信息增量、跟读者关系（跟读者关系权重提至15%）
- **普通人落点分层**：钱包/工作/谈资三落点，选题必标一个（优先钱包/工作）
- **竞争饱和度检查**：评分前必做，同角度被写烂则放弃或换角度
- **新鲜度预检三问**：防"对普通读者已过时"的新闻（对读者算新吗/已有先例吗/有增量吗）
- **话题生命周期分析**：5阶段 + 量能判断（识别真爆发vs假信号）
- **6法角度设计**：反常识/信息增量/身份代入/冲突对比/趋势预判/**熟人故事**（实盘最高效）
- **4类选题范式**：热点借势 / 认知突破 / 实用干货 / 利益相关（头条翻译版）
- **头条双模式选题**：微头条选题 vs 长文选题分开选 + 长文先微头条探路
- **微头条快速选题通道**：5分钟定题动作清单（用户驱动即时发）
- **数据回填闭环**：失败归因（6证据交叉表）+ 成功数据回填校准判断标准
- **爆款变体对接**：爆款≥3倍基线 → 3个变体方向入库 → 分批测试
- **低粉高展现监控**：头条版真实流量信号（每周一扫描）
- **读者反应验证**：发稿前饭桌测试（最后一道闸）
- **语气设计**：5种语气（冷峻拆解/幽默反讽/焦虑预警/自豪叙事/科普解惑）
- **评论挖掘法**：含5步可执行操作流程，从爆款评论找选题
- **SEO关键词热度评分** + **品牌匹配检查**
- **选题库管理**：含专题/系列/落点/配方/扩文/变体字段（点状→线状）
- **17项检查清单**：含钩子强度自评（1-5分）
- **三方圆桌选题**：重要选题走智囊团3+博主团2+李继刚1 对轮出题

## 怎么用

1. 先判定：微头条选题 or 长文选题？（双模式分开选）
2. 微头条·用户要发 → 走**快速选题通道**（5分钟定题）；重要/当晚主推 → 三方圆桌；常规 → 标准流程
3. 扫描信息源 + 低粉高展现监控，收集候选选题
4. 品牌匹配3问 → 一句话内核三问 → 新鲜度预检 → 竞争饱和度
5. 话题生命周期判断 + 量能验证
6. 5维评分，≥3.0入库；**落点必标（钱包/工作/谈资）**
7. 归入专题/系列
8. 从高优先级选题中选1个，6法设计角度 + 4类范式 + 选语气 + 评论挖掘验证
9. 过17项检查清单（含饭桌测试）
10. 长文选题先微头条探路（数据过线再升级长文）
11. 交给写作Skill产出
12. 发布后7天回填数据 + 失败归因；爆款走变体

详细使用流程见 [SKILL.md](./SKILL.md)。

## 与其他Skill的协作

| Skill | 职责 |
|-------|------|
| **ian-topic-finder**（本Skill） | 写什么（选题+角度+语气+落点+范式） |
| ian-toutiao-writer | 怎么写（标题/开头/结构/金句/结尾） |
| ian-illustration-master | 配图（封面+插图） |
| ian-typography-master | 排版（可读性） |
| toutiao-publisher | 发布（上传到平台） |
| tuxianrentoutiao-clone | 运营总控/配方轮换/时段/扩文判断（**协作接口**：本skill只标注消费） |
| traffic-coach | 数据判级/账号基线/爆款变体（对接§11.7回填/§11.8变体） |
| tianya-gods-team / ian-blogger-review / 李继刚 | 三方圆桌选题（重要选题） |

**控制变量法**：每个Skill的效果可独立验证——选题看点击率，写作看完读率，配图看点击率提升，排版看完读率；选题改良看"落点命中与爆款的相关性"。
