# 头条选题操作系统（ian-topic-finder）

> 全网最好的头条选题工具——从信息洪流中，用"真实信号 × 严苛闸门 × 头条落点 × 数据闭环"筛出能爆的好选题。
>
> **版本**：v0.7.0｜ **创建**：2026-08-31｜ **更新**：2026-09-03

---

## 这是什么

一个选题Skill，帮你解决"今天写什么"的问题。

核心信念：**选题决定下限，写作决定上限。好选题 = 真实信号 × 独特角度 × 读者身份。**

**v0.7.0 定位**：从"方法论文档"升级为"选题操作系统"——四层协同：信号层（输入）→ 闸门层（筛选）→ 落点层（决策）→ 闭环层（回灌），越用越准。

## 能做什么

**信号层（输入，不靠猜靠信号）**：
- **AIHOT 实时热点接口**：匿名REST API自动供题（24h精选/热点榜/日报）
- **评论区高赞采样**：别家爆款评论区高赞=读者真实反应，三用途（选题/角度/给博主团参照）
- **博主跟踪信号路**：跟踪一批认可的博主（产业媒体/个人创作者/判断型），他们发什么=已筛选的真实信号，自带二创素材
- **信息源监控**：AI+时政、AI+汽车、通用热点三大类，20+信息源
- **低粉高展现监控**：头条正在喂流量的真实信号（每周一扫描）

**闸门层（筛选，防旧闻/防写烂/防HBM事故）**：
- **品牌匹配** → **一句话内核三问** → **新鲜度预检**（防旧闻）→ **竞争饱和度**（防写烂）
- **证据强度分级 A/B/C/D**：D级传闻一票否决，C级标单源风险（防HBM事故）
- **换角度复活依赖检查**：防D级传闻换壳混进来
- **可核查性预检三问**：出题前最后核验
- **反自嗨协议**：防三引擎集体自嗨

**落点层（决策，头条专属）**：
- **5维评分**（行为锚定1/3/5防打分漂移，跟读者关系权重15%）
- **普通人落点分层**：钱包/工作/谈资必标一个（优先钱包/工作）
- **6法角度设计**：反常识/信息增量/身份代入/冲突对比/趋势预判/**熟人故事**（实盘CTR15%+）
- **4类选题范式** + **5种语气**
- **头条双模式选题**：微头条 vs 长文分开选 + 长文先微头条探路
- **微头条快速选题通道**：5分钟定题（第1分钟接AIHOT+评论区高赞+博主跟踪）
- **三方圆桌选题**：题材路由选人 + 两轮淘汰 + 初筛分=质询顺序
- **二创机制**：引用/延伸/反驳三态，用他的料做我们的判断（防洗稿红线）

**闭环层（回灌，越用越准）**：
- **数据回填闭环**：失败归因（6证据交叉表）+ 成功数据回填校准
- **用户拍板信号入库**：你选/不选/主动提=最高权重信号（没选=真实反馈）
- **台账强制触发**：出题必记/发稿必记/每5篇必复盘（不记=违规）
- **来源路复盘**：每5篇按数据更新五路供题权重
- **爆款变体对接**：爆款≥3倍基线 → 3个变体方向 → 分批测试

**22项检查清单**：发稿前必过。

## 怎么用

1. 先判定：微头条选题 or 长文选题？（双模式分开选）
2. 微头条·用户要发 → 走**快速选题通道**（5分钟定题）；重要/当晚主推 → 三方圆桌；常规 → 标准流程
3. 扫描信号（AIHOT接口 + 低粉高展现 + 评论区高赞），收集候选选题
4. 过闸门：品牌匹配 → 一句话内核三问 → 新鲜度预检 → 竞争饱和度 → 证据分级 → 换角度依赖检查
5. 生命周期判断 + 量能验证
6. 5维评分（行为锚定），≥3.0入库；**落点必标（钱包/工作/谈资）**
7. 归入专题/系列
8. 6法设计角度 + 4类范式 + 选语气 + 评论挖掘验证
9. 可核查性预检三问
10. 过22项检查清单（含饭桌测试 + 反自嗨 + 二创红线）
11. 长文选题先微头条探路（数据过线再升级长文）
12. 交给写作Skill产出
13. 发布后7天回填 + 失败归因 + 用户拍板信号入库；爆款走变体；每5篇来源路复盘

详细使用流程见 [SKILL.md](./SKILL.md)。

## 与其他Skill的协作

| Skill | 职责 |
|-------|------|
| **ian-topic-finder**（本Skill） | 写什么（选题+角度+语气+落点+范式） |
| ian-toutiao-writer | 怎么写（标题/开头/结构/金句/结尾） |
| ian-illustration-master | 配图（封面+插图） |
| ian-typography-master | 排版（可读性） |
| toutiao-publisher | 发布（上传到平台） |
| tuxianrentoutiao-clone | 运营总控/配方轮换/时段/扩文判断（**协作接口**：本skill只标注消费） |
| traffic-coach | 数据判级/账号基线/爆款变体（对接回填/变体） |
| tianya-gods-team / ian-blogger-review / 李继刚 | 三方圆桌选题（重要选题，题材路由选人） |

**控制变量法**：每个Skill的效果可独立验证——选题看点击率，写作看完读率，配图看点击率提升，排版看完读率；选题改良看"落点命中与爆款的相关性"。
