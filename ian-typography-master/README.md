# 通用排版大师Skill v2.0.0 - 简洁清爽版

与「通用配图生成大师Skill」配套的**排版方法论**，专注于文章排版优化，确保排版风格与配图风格完全统一，提升文章可读性、完读率和专业感。

## ⚠️ v2.0.0核心升级（最重要！）

**解决v1.0太复杂的问题，吸取做图skill经验**：

1. **10项必选排版元素清单**：标题、开头钩子、小标题、正文段落、数据高亮、观点强调、引用块、列表、配图、结尾互动，每篇文章必须包含
2. **简洁清爽排版原则**：颜色原则（只使用3种彩色+黑白）、字体原则（只使用2种字重+2种样式）、装饰原则（不使用渐变/阴影/复杂边框/emoji）、留白原则（段间空行+足够留白）
3. **排版负面清单**：5大类绝对不要做的事情（不要花哨装饰、不要乱用颜色、不要乱用字体、不要排版混乱、不要影响阅读）
4. **排版前检查清单**：10项，排版前必须逐项确认
5. **排版后检查清单**：10项，不合格必须返工，最多返工3次
6. **标准排版参考**：孙宇晨文章v7简洁版作为标准参考

## 核心特色

## 与配图大师skill的关系

- 配图大师skill负责「画什么、怎么画」
- 排版大师skill负责「文字怎么排、图文怎么配合」
- 两者风格统一，共同构成完整的内容视觉体系

## v2.0.0 10项必选排版元素速查

| 序号 | 必选元素 | 标准样式 |
|------|---------|---------|
| 1 | 标题 | 20-30字，加粗22px，包含核心关键词 |
| 2 | 开头钩子 | 前3行抓住读者，短段落1-2行，直接切入 |
| 3 | 小标题 | 统一编号（一、二、三），加粗18px，左边框4px红色 |
| 4 | 正文段落 | 16px，行间距1.8，每段不超过3行，段间空行 |
| 5 | 数据高亮 | 核心数据橙色（#FB8C00）加粗，每段不超过3处 |
| 6 | 观点强调 | 核心观点黑色加粗，不使用颜色 |
| 7 | 引用块 | 灰色背景（#f9f9f9）+左边框3px灰色+斜体，不超过3行 |
| 8 | 列表 | 默认圆点/数字，不超过7项，前后空行 |
| 9 | 配图 | 5-6张，位置在小标题上方，图注灰色13px居中 |
| 10 | 结尾互动 | 灰色背景文字块，总结+开放性问题引导评论 |
